# فاکتورساز

اپلیکیشن فارسی فاکتور با ذخیره‌سازی محلی و کارکرد آفلاین. اطلاعات مشتری، کالا، فاکتور و پرداخت به سرویس مجوز ارسال نمی‌شوند.

## اجرا

نیازمند Node.js نسخه ۲۲٫۵ یا جدیدتر است. فایل `.env.example` را به `.env` کپی و سپس `npm start` را اجرا کنید. برنامه و API مجوز به‌طور پیش‌فرض فقط روی `127.0.0.1:4173` در دسترس‌اند. پایگاه داده تجاری در مرورگر و سفارش/مجوزها در SQLite محلیِ سرویس نگهداری می‌شوند.

## محدوده API مجوز

- `POST /api/orders`: ایجاد سفارش و هدایت به صفحه میزبانی‌شده درگاه، فقط با آداپتور درگاه.
- `POST /api/payment/webhook`: دریافت وب‌هوک امضاشده واریزا با هدر `X-Webhook-Signature`.
- `GET /api/orders/:id?installationId=...`: دریافت وضعیت سفارش و توکن پس از تأیید پرداخت.
- `POST /api/licenses/verify`: اعتبارسنجی توکن امضاشده برای نصب محلی.
- `POST /api/licenses/recover`: بازیابی خرید با کد بازیابی.

مرورگر برای خرید فقط شناسه نصب و کلید یکتای سفارش می‌فرستد. مبلغ از سرور تعیین می‌شود. وب‌هوک با HMAC روی بدنه خام بررسی می‌شود و شناسه لینک و مبلغ پایه با سفارش تطبیق داده می‌شود. بازگشت کاربر از درگاه به‌تنهایی مجوز صادر نمی‌کند.

## پیکربندی خرید

اتصال واریزا در `payment-adapter.js` پیاده‌سازی شده است. فایل `.env.example` را با اطلاعات واقعی پر کنید. مبلغ `PRO_PRICE_MINOR` به ریال است و مبلغ ارسالی به واریزا بر حسب تومان محاسبه می‌شود؛ مقدار پیش‌فرض ۱٬۹۹۰٬۰۰۰ ریال برابر ۱۹۹٬۰۰۰ تومان است.

در پنل واریزا، آدرس وب‌هوک را روی `https://دامنه-شما/api/payment/webhook` ثبت کنید و مقدار `webhook_secret` پنل را در `PAYMENT_WEBHOOK_SECRET` بگذارید. `PUBLIC_APP_URL` باید آدرس HTTPS برنامه باشد. `VARIZA_API_KEY` را از پروفایل واریزا دریافت کنید. `VARIZA_CARD_LAST_4` اختیاری است: اگر خالی بماند، تنظیم پیش‌فرض حساب اعمال می‌شود؛ مقدار `variza` از کارت‌های واریزا استفاده می‌کند و به قابلیت متناظر اشتراک نیاز دارد؛ یا چهار رقم پایانی کارت مقصدتان را وارد کنید. `LICENSE_SIGNING_SECRET` و `PAYMENT_WEBHOOK_SECRET` باید رازهای مستقل باشند. برای آزمایش محلی، سرویس واریزا باید بتواند به وب‌هوک عمومی HTTPS دسترسی پیدا کند.

صفحه درباره ما در مسیر `/about.html` قرار دارد و از منوی کناری برنامه نیز در دسترس است. اطلاعات تماس در فایل صفحه خالی گذاشته شده تا فقط راه‌های ارتباطی تأییدشده‌ی پروژه نمایش داده شوند.

## داده‌ها

IndexedDB با نام `InvoiceMakerDB` و migration نسخه‌بندی‌شده محل داده‌های کاری است. فایل پشتیبان نسخه‌بندی‌شده با AES-GCM و PBKDF2 رمزگذاری می‌شود. مجوز Pro در پشتیبان کاری صادر نمی‌شود تا عملیات جایگزینی داده‌ها آن را پاک نکند.
